## Verify your download

Every release publishes SHA-256 checksums in `SHA256SUMS.txt`. Auto-updates check both the checksum and the minisign signature embedded in `latest.json` before they install.

```sh
shasum -a 256 kurlo-*.dmg
# Compare against the value in SHA256SUMS.txt on the release page.
```

## Older releases

Every published version stays on the releases page. If you need an older build, browse the [full release list](https://github.com/stormhop/kurlo/releases) and pick a tag.

## Build from source

Kurlo is open source under the MIT license. Clone [stormhop/kurlo](https://github.com/stormhop/kurlo) and follow the [build instructions](https://github.com/stormhop/kurlo#building-from-source) — you need Go, Node.js and Wails v2.
