## Verify your download

Every release includes a `SHA256SUMS.txt` file. Use the command for your platform and compare the result with the checksum for the same filename.

See [Verify downloads](/docs/getting-started/installation/verify/) for the commands and how Kurlo verifies signed auto-updates.

## Older releases

Find previous versions and their installers in the [GitHub release archive](https://github.com/stormhop/kurlo/releases).

## Build from source

Kurlo is open source under the MIT license. Follow the [build instructions](https://github.com/stormhop/kurlo#building-from-source) to compile it with Go, Node.js, and Wails v2.
