Kurlo publishes a build for each platform on the [releases page](https://github.com/stormhop/kurlo/releases/latest). Code signing differs by platform and file, so each section below ends with what to expect on the first launch.

## macOS

**Requirements:** macOS 12 (Monterey) or later, with system updates installed — Kurlo draws its window with the system WebKit and needs the version that ships with Safari 16.2 or newer. Apple Silicon and Intel are both supported.

<Steps>

1. Download `kurlo-<version>-darwin-universal.dmg`.

2. Open the disk image and drag **Kurlo.app** to `/Applications`.

3. Launch Kurlo from Spotlight or the Applications folder.

</Steps>

Current builds are not Apple-notarized. On the first launch, right-click **Kurlo.app** and choose **Open**, or use *System Settings → Privacy & Security → Open Anyway*. See the [troubleshooting guide](/docs/troubleshooting/#macos-kurlo-cant-be-opened-because-apple-cannot-check-it-for-malicious-software).

## Windows

**Requirements:** Windows 10 1903+ or Windows 11, on x64 or Arm64. Pick the files ending in `amd64` for an Intel or AMD processor and `arm64` for a Snapdragon or other Arm processor; *Settings → System → About → System type* says which one you have.

If an older copy installed for all users in Program Files is found, the installer offers to remove it; Windows asks for permission once for that, and your data is kept. SmartScreen may warn because the installer is not Authenticode-signed yet. The MSIX package is signed only when the release job had the publisher certificate; an unsigned package needs extra trust setup before Windows installs it.

## Linux

**Requirements:** x64 with Ubuntu 22.04 or later, Debian 12 or later, or Fedora 37 or later, plus GTK 3, WebKitGTK 4.1 and FUSE 2 from your distribution's package manager.

<Steps>

1. Install the libraries Kurlo draws its window with:

   ```sh
   sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0 libfuse2   # Ubuntu, Debian
   sudo dnf install gtk3 webkit2gtk4.1 fuse-libs              # Fedora
   ```

2. Download `kurlo-<version>-linux-amd64.AppImage`.

3. Make it executable and run it:

   ```sh
   chmod +x kurlo-*.AppImage
   ./kurlo-*.AppImage
   ```

</Steps>

## Verify the download

SHA-256 checksums are published in `SHA256SUMS.txt`; auto-updates use the values embedded in `latest.json`. Verify before running:

```sh
shasum -a 256 kurlo-*.dmg
# Compare against the value on the releases page.
```

## Auto-updates

Kurlo checks `latest.json` from `stormhop/kurlo` after launch. Open **Settings → About** to check and install by hand. **Settings → About → Install updates automatically** controls whether a discovered update installs in the background.

Updates are verified against both the SHA-256 value and the minisign signature from the manifest before they install.

An AppImage updates in place: Kurlo replaces the `.AppImage` file you started it from, so keep that file in a folder you can write to, such as `~/Applications`. AppImages from Kurlo 2.2.3 and earlier cannot install updates. Download 2.2.4 or later by hand once, and updates install from then on.
