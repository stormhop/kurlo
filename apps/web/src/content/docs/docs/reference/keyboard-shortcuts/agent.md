## Agent

| Shortcut | Action |
|----------|--------|
| `Enter` or `Cmd/Ctrl Enter` | Send the message |
| `Shift Enter` | New line in the message |
| `Cmd/Ctrl F` | Search chats |
| `F2` | Rename the selected chat |
| `Cmd/Ctrl W` | Close the Agent tab and keep its draft |
| `Escape` | Close the agent picker, a menu or chat details |

While the Agent tab is open, [request editor](/docs/reference/keyboard-shortcuts/requests/) and [sidebar](/docs/reference/keyboard-shortcuts/sidebar/) shortcuts such as Send, Copy as cURL, Find and replace, and Delete selection are disabled. Arrow keys scroll the chat. Tab, zoom, search, settings and **Show** shortcuts work everywhere.
