title: Support Kurlo
description: Kurlo is free for teams of any size. Here is how to help it keep going.
---

Kurlo has no paid plan and will not get one. Every feature is in the free, [MIT-licensed](https://github.com/stormhop/kurlo/blob/main/LICENSE) app, with no account and no seat limit.

## Support development on Boosty

If Kurlo saves you time, you can support it on [Boosty](https://boosty.to/kurlo) with a monthly subscription or a one-time tip. The money pays for the server, macOS code signing and the time that goes into new features.

Supporters get:

- posts on what is being built and what comes next;
- release candidates before each public release;
- a vote on upcoming features.

## Other ways to help

- [Star Kurlo on GitHub](https://github.com/stormhop/kurlo). A star helps other people find it.
- [Report a bug or ask a question](https://github.com/stormhop/kurlo/issues). In the app, **Settings → Support → Copy diagnostics** collects the details that help fix it.
- [Contribute](https://github.com/stormhop/kurlo/blob/main/CONTRIBUTING.md) code or docs.

The Boosty link is also in the app under **Settings → Support**.
